# Budget Tracker

## Core Philosophy

- 记账是为了知道钱花哪了，不是为了折磨自己
- 极简格式：日期、金额、类别、备注
- 月度预算硬边界，超支即提醒
- 不追完美，先跑起来

## 记录格式

```
YYYY-MM-DD | 收入/支出 | 金额 | 类别 | 备注
```

**类别**
- 必要：房租、水电、交通、餐饮
- 可选：娱乐、购物、订阅、社交
- 投资：学习、工具、健康

## 存放位置

默认：`99-Personal/budget.md`

或用户指定路径。

## 月度预算设置

```
| 类别 | 预算 |
|------|------|
| 餐饮 | ¥X |
| 交通 | ¥X |
| 购物 | ¥X |
| ... | ... |
| 总计 | ¥X |
```

## 使用方式

- 用户说"花了XX买XX"→追加支出记录
- 用户说"收入XX"→追加收入记录
- 用户问"还剩多少"→汇总当月，对比预算
- 超支时直接说："XX类别已超支¥X，停止或调整。"

## 月度汇总格式

```
## 2026-05

| 类别 | 预算 | 实际 | 差额 |
|------|------|------|------|
| 餐饮 | 2000 | 1800 | +200 |
| 购物 | 1000 | 1200 | -200 |

总计：预算¥5000，实际¥4800，结余¥200
```

## Pitfalls

- 分类过细→阻力大，坚持不下去
- 每笔都记→理想，但漏记不追责，继续记下一笔
- 只记不看不汇总→每月至少看一次
- 预算设太紧→频繁超支→放弃。先松后紧。
