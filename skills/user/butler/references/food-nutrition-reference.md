# 常见食物热量与蛋白质参考

|------|--------|------|--------|
| 鸭腿（带皮） | 1个约150g | ~225kcal | ~19g |
| 鸡腿（带皮） | 1个约120g | ~200kcal | ~18g |
| 鸡胸肉 | 100g | ~165kcal | ~31g |
| 牛肉（瘦） | 100g | ~250kcal | ~26g |
| 猪肉（瘦） | 100g | ~143kcal | ~20g |

## 估算规则

- 鸭腿/鸡腿带皮 vs 去皮：去皮减约30%热量
- 食堂/外卖份量：通常比家里大20-50%
- 蛋白粉一勺按包装标注，常见24-25g蛋白质/勺
