# 备忘录更新模式

## 追加格式规则

用户明确要求：
- **无时间前缀** — 只写纯内容，不写 `YYYY-MM-DD HH:MM |`
- **每条前空一行** — 与上一条保持间隔
- **自动创建** — 当天日记不存在时自动创建

## 追加脚本（bash）

```bash
# 追加到备忘录（空一行 + 内容）
printf "\n\n内容" >> "/path/to/note"

# 追加到 Obsidian 日记
printf "\n\n内容" >> "/path/to/98-Days/YYYY/YYYY-MM-DD.md"
```

## 问题总结写入日记

询问场景结束后，总结格式：

```
询问总结：[问题简述]
- [要点1]
- [要点2]
```

## 备忘录 vs Obsidian 分工

| 内容 | 位置 | 原因 |
|------|------|------|
| 训练/护肤/记账记录 | Apple 备忘录 | 手机随时查看，长期跟踪 |
| 日常碎片/询问总结 | Obsidian 日记 | 日记流，事后回顾 |
| 食物蛋白质参考 | 已删除 | 信息在训练记录的饮食计划里 |
