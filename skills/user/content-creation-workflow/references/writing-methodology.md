# 公众号爆款文章写作法（Reference）

## 核心信念

**AI写的文章像一条直线。人写的文章像一条小径。**

你不需要让文章变得更好。你需要让文章变得更像一个人在说话。

**爽大于对。**

读者刷手机时不是在"求知"，是在"求认同"——寻找能印证自己想法的东西。一个明确但极端的观点，比模糊的正确更有传播力。自媒体交易的不是信息，是情绪确认。

- "对"是防御性的：你怕得罪人，所以写得面面俱到、人人都认可，结果谁也记不住。
- "爽"是进攻性的：你给出立场，即使是反常识的，同频的人瞬间被拉到一起。

这里的"错"不是逻辑错误，是**不认同大众价值观**。你不是在"教读者做人"，是在"告诉他们你跟他们想的一样"。类似"赢学"——让受众感觉自己"赢了"、"对了"，比让他们"学到了"更有传播力。用"爽的方式讲对的事情"——情绪拉满，底层逻辑经得起推敲。机器可以生产正确的废话，但制造"爽感中的真实共鸣"才是人的壁垒。

## 一、去AI化七条人味法则（绝对优先）

### 法则一：不要写得太"正确"
- 不要中立，要有立场。"我告诉你，A就是对的"
- 不要全面，要有偏好。"我最喜欢的是第二个故事"
- 允许结构"破烂"。中间突然插一句看似无关的话

### 法则二：用"具体"杀死"抽象"
- 数字精确到"不合理"。105美元，不是"一百多"
- 不要"一个程序员"，要"做Java的二十八岁小伙，头发已经快掉完了"
- 地点要具体到街道名。"成都三圣乡那个转角"

### 法则三：让文章有"口水残渣"
- 口头禁："说白了"、"你懂我意思吧"、"对吧"、"讲真的"
- 自我打断："等会儿说"、"这个等下再讲"
- 故意重复："好，很好，好得很"
- 口误感："三个人有两个脸"——AI会写"两种表情"

### 法则四：段落长度要"不规则"
- 突然一句话成段："为什么？"
- 突然一大段（但不超过6行）
- 有的1行，有的2行，有的5行。不要均匀
- 最长的段落后面，紧跟最短的段落

### 法则五：情绪不要"正确"，要"真实"
- 不要总是鼓励。"这个我也做不到"、"这个真的很难"
- 不要怕写"丧"。"我当时觉得自己快完了"
- 允许矛盾。"我既觉得公平，又觉得不公平。这两件事不矛盾。"
- 突然想到一件不相关的事，写下来，然后说"这个等会儿再讲"

### 法则六：不要"解释"，要"告诉"
- 少用"这意味着"、"换句话说"、"从某种意义上讲"
- 用"你看"代替"也就是说"
- 用"这么说吧"代替"简而言之"

### 法则七：结尾不要"总结"，要"余音"
- 不要"综上所述"、"总的来说"
- 结尾可以是问号："你说是不是这个道理？"
- 结尾可以是动作："去试试看吧。"
- 结尾可以没说完："桑德斯上校 65 岁才走出厨房。"

## 二、整体写作框架

```
1. 钩子：反常识故事（具体人物 + 极端反差 + 精确数字）
   ↓
2. 抛出核心观点（用金句一击即中）
   ↓
3. 理论支撑（引用权威 + 大白话翻译）
   ↓
4. 第二个故事（更贴近读者，反差人设）
   ↓
5. 极简模型（四字诀 / 三步法 / 一个公式）
   ↓
6. 具体建议（3条，每条都可马上去做）
   ↓
7. 金句收尾（三板斧：闭环 + 行动 + 情绪）
```

**结构要点**：
- 双故事线：远的故事 vs 近的故事形成呼应
- 理论与故事穿插：每讲完一个概念，立刻用故事落地
- 从远到近：历史/名人 → 身边人 → 读者自己

## 三、开头钩子

### 模板一：反常识故事钩子（首选）
**公式**：
```
[具体时间/地点]，[具体人物]……
[建立正面预期，用数字强化]……
但是——注意这个但是——[极端反差的结局，精确数字]。
```

**去AI化变体**：
- 不要总是"但是——注意这个但是——"。有时候可以"但是呢？他 65 岁的时候身上只剩 105 美元。对，就是那个炸鸡的桑德斯。"
- 可以"跳跃式"开头："你知道桑德斯上校 65 岁的时候身上有多少钱吗？105 美元。就那么多。"
- 数字必须是自己编的，精确到诡异

### 模板二：直接挑战共识
**公式**：
```
[人人都信的常识]……
这个逻辑听起来太对了。对到你从来不会怀疑它。
但我跟你说一个[权威身份]的发现。
```

### 模板三：数字冲击
**要点**：用精确数字（1009 次）而非概数（上千次），数字自带信任感。

### 开头公式（通用检验）
```
开头 = 话题（讲什么）+ Hook（为什么看）+ 可信度（为什么信你）
```
**例子**：「我去年涨粉 200 万，靠的就是搞清楚选题和标题的区别」
- 话题：选题和标题的区别
- Hook：去年涨粉 200 万
- 可信度：靠的就是这个

**原则**：开头必须独立工作，不能假设读者看了标题。开头要在 5 秒内建立吸引力。

### 素材5维检查表（写前必查）
动笔前先列这5项，缺3项以上说明素材不够，别硬写：

| 维度 | 检查项 | 例子 |
|------|--------|------|
| 数据 | 大数字、对比数字、百分比 | 80亿、从0到X、99% |
| 转变 | 之前vs之后，反差越大越好 | 从攒首付到管理80亿 |
| 金句 | 能独立成立、可传播 | "不能持有10年，就不要持有10分钟" |
| 权威 | 人物或机构背书 | 巴菲特、500强 |
| 痛点 | 目标人群的焦虑 | "研究了3个月，焦虑了3年" |

### 悬念制造法则
- 不要直接给答案
- 用"为什么"而不是"证明"
- 用"问题"而不是"结论"

**对比**：
- ❌ 李亚鹏30年干黄十几个项目，证明人脉不等于赚钱 ← 说了答案
- ✅ 善良的李亚鹏，认识半个娱乐圈，30年为什么赚不到钱 ← 留悬念

## 四、情绪节奏控制

### 整体情绪曲线
```
好奇 → 震惊 → 疑惑 → 认同 → 打击 → 重建 → 希望 → 行动
```

**去AI化升级**：
- 情绪不是完美曲线，是一团毛线。允许回溯
- 不要每个转折都是"但是"。有时候只是"然后"、"接着"
- 允许"跑题"。中间突然插一段看似无关的细节
- 情绪高潮在偏后一点的地方，不在正中间

### 手法一：刹车感
- "但是——注意这个但是——"
- "问题就出在这里"
- "这时候，一件他们谁都没想到的事发生了"

### 手法二：快—慢—快（段落呼吸）
| 文章位置 | 理想行数 | 风格 |
|---------|--------|------|
| 开头钩子 | 1-3 行 | 短、快、有画面 |
| 故事叙事 | 2-5 行 | 分段多，一段一个情节 |
| 论点阐述 | 3-6 行 | 可以长，但每段结尾要有金句 |
| 金句收尾 | 1-2 行 | 短到极致，10 字以内 |
| 行动号召 | 1-2 行 | 短句，直接 |

### 手法三：反问接力
用问号控制节奏，问题之后必须紧跟答案。
- "手艺好不好？好得很。"
- "为什么？"
- "这个故事有意思的地方在哪呢？"

### 手法四：降维打击
引用权威后，用"大白话"重新说一遍。
```
[权威名言]
这句话翻译成大白话就是：[口语化翻译]
```

### 手法五：收尾加速度
最后三段，逐段变短，一句比一句短。

## 五、金句公式（每 400-500 字一个）

金句标准：读完之后想给别人看，但说不出为什么好。

**去AI化原则**：
- 不要叫它"公式"。叫它"让人过目不忘的说话方式"
- 不要按顺序用全部公式。一篇文章最多用2-3个
- 金句不要太漂亮。可以"残缺"，可以不对称

### 公式一：反差金句
**结构**：[被广泛认同的事] + [但是] + [被忽视的真相]
> "擅长做一件事，是'有价值'。但有价值不等于能变现。"

### 公式二：比喻降维
**结构**：抽象 → 日常物体
> "一座金矿埋在地底下……跟一堆石头没有任何区别。"

### 公式三：数字锚定
**结构**：[精确数字] + [人生节点式感悟]
> "被拒绝了 1009 次，才找到第一个愿意加盟的餐厅老板。"

### 公式四：重新定义
**结构**："不是 X，是 Y"
> "财富是你睡觉的时候还在为你赚钱的资产。注意，他说的是'资产'，不是'技能'。"

### 公式五：场景代入
**结构**：[你一定经历过的场景] + [从未注意到的细节]
> "你厨艺再好，如果你只在自己家厨房炒菜，你的手艺就是零。"

### 公式六：短句暴击
**结构**：10 个字以内
> "厨子要想赚钱，得先走出厨房。"

### 金句生成流程
1. 找出核心观点
2. 删掉一切"其实""总之""可以说"等缓冲词
3. 寻找对比或比喻
4. 压缩到最短（删到再删一个字就变意为止）
5. 用第二人称检验："你"字越多，代入感越强

## 六、故事叙事技巧

### 有效故事的要素
| 要素 | 作用 |
|------|------|
| **反差人设** | 年薪 50 万 Java 专家去摆摊贴膜 → 好奇 |
| **具体数字** | 2 个周末、600 块、11 个人、99 块 → 真实感 |
| **学习过程** | 不是成功学，而是观察隔壁摊位 → 可复制 |
| **金句收尾** | 概念验证，一句记住 |

### 故事结构
```
困境 → 行动 → 顿悟 → 迁移 → 结果
```

## 七、建议部分写法

三条建议，每条都**极其具体**，可马上去做。
- 有具体动作："请他吃饭"、"闲鱼卖键盘"、"每周拿 1 小时"
- 有具体数字

## 八、金句收尾三板斧

结尾必须包含三种力量：

1. **情绪板斧**：民间智慧式语句
   > "厨子要想赚钱，得先走出厨房。"
2. **闭环板斧**：回到开头的故事或核心比喻
   > "桑德斯上校 65 岁才走出厨房。"
3. **行动板斧**：给读者希望，人人可做
   > "你不用等那么久。"

**收尾节奏**：
```
[金句本身]（12 字以内）
  ↓
[回扣开头]（7 个字左右）
  ↓
[行动号召]（8 个字以内）
```

## 九、去 AI 化禁忌清单

### ❌ 绝对禁用词汇
- 首先 / 其次 / 最后 / 第一 / 第二 / 第三
- 综上所述 / 总而言之 / 总的来说 / 归根结底
- 值得注意的是 / 不难发现 / 显而易见
- 在这个……的时代 / 随着……的发展
- 让我们…… / 我们需要…… / 我们应该……
- 从某种意义上讲 / 换句话说 / 这意味着
- 其实 / 可以说 / 也就是说
- 重要的是 / 关键在于 / 核心在于

### ❌ 禁用句式
- "在这个信息爆炸的时代……"
- "随着社会的发展……"
- "你是否曾经想过……"（太泛）
- 定义式开头："赚钱，是指……"
- 排比句堆气势
- 连续三段超过 6 行

### ✅ 必须用
- 第二人称"你"（全文至少 20 次）
- 设问句（问号控制节奏）
- 动词优先（"走出厨房"、"拿着锤子"、"拧螺丝"）
- 一句一段（手机阅读友好）
- 口语残渣（"说白了"、"你懂吧"、"对吧"）
- 具体数字（精确到不合理的程度）

## 十、自检清单（生成后必须检查）

### 第一步：禁用词检查
用 Ctrl+F 搜索以下词汇，结果必须为 0：
- [ ] 首先 / 其次 / 最后
- [ ] 综上所述 / 总而言之 / 总的来说
- [ ] 值得注意的是 / 不难发现 / 显而易见
- [ ] 在这个……的时代 / 随着……的发展
- [ ] 让我们…… / 我们需要……
- [ ] 从某种意义上讲 / 换句话说 / 这意味着
- [ ] 其实 / 可以说 / 也就是说

### 第二步：结构检查
- [ ] 有没有连续三段超过 6 行？
- [ ] 有没有连续三段长度一模一样？
- [ ] 全文"你"字是否超过 20 次？
- [ ] 有没有至少一个只有 1 行的段落？
- [ ] 有没有至少一个具有"口误感"的句子？

### 第三步：情绪检查
- [ ] 文章里有没有至少一处"突然低落"？
- [ ] 有没有至少一处"突然跑题"？
- [ ] 结尾是否"太漂亮"了？如果太漂亮，打破它
- [ ] 有没有至少一个让读者想"这人怎么突然说这个"的地方？

### 第四步：最终测试
把文章念出声来。如果你觉得自己在"朗读论文"，那就还是AI味。如果你觉得自己在"跟朋友吹牛"，那就对了。

---

### 第五步：五维诊断

| 维度 | 检查项 | 判断 |
|------|--------|------|
| 文字洁癖 | Emoji堆叠、歪涩词汇、空洞排比？语言是否公共可验证？ | ✅干净 / ⚠️有AI味 / ❌需重写 |
| 标题 | 平铺直叙能否吸引人？情绪是信息传递还是认知劫持？ | ✅自带吸引力 / ⚠️需优化 / ❌需重做 |
| 表达效率 | 能否一句话说清核心观点？99%时间是否在包装1%的内容？ | ✅高效 / ⚠️有冗余 / ❌本末倒置 |
| 认知落差 | 同行讲清楚了吗？你好在哪？受众看完会不会觉得"这个我知道"？ | ✅有明显落差 / ⚠️落差较小 / ❌无落差 |
| AI辅助 | 观点类=长思考快输出；分析类=get笔记→deep search→改写 | 确认工作流匹配 |

**特别警告：**
- 99%时间应该花在做值得讲的事上，标题只需要1%
- 所有让你讲干货的博主都是不专业的。你要做的是把事情搞清楚，然后说清楚
- 先有产品后有内容。你的付款链接在哪？

## 十一、人称转换策略

| 阶段 | 主要人称 | 作用 |
|-----|--------|------|
| 开头故事 | 第三人称（他） | 建立客观性、好奇心 |
| 核心观点 | 第二人称（你） | 打破第四面墙，与读者对话 |
| 案例进一步 | 第三人称（他） | 提供"安全距离"，让读者安全观察 |
| 行动建议 | 第二人称（你） | 回到读者，给出可执行的事项 |

## 十二、AI指纹22条检测清单

### 核心哲学
1. **AI味的本质是「太完美」**：没有毛边、没有卡顿、没有跑题，完美本身就是不真实的信号。
2. **去AI味 ≠ 好内容**：花时间去AI味不如花时间把事情搞清楚。英雄不问出处。
3. **改写必须基于自己的偏好**：每个AI特征背后都有一个你本来想达成的目的。

### 22条特征与追问

**特征1 — 堵住所有反驳**
追问：你堵了这些反驳，哪个是你真的被人问过的？只留那个。

**特征2 — 知识全部输出**
追问：你堆了这么多术语和数据，哪一个是你真正用来想事情的？留那一个。

**特征3 — 均速排比**
追问：这几句排比里，哪一句是你最想说的？把那一句加长或换说法，打破均匀。

**特征4 — 同一个让步模板反复用**
追问：你走了三遍同一个让步结构，后面的能不能换个说法，或直接跳过？

**特征5 — 给概念起名字的仪式**
追问：你给了几个概念起名字，哪个名字是你真觉得精准的？留那一个。

**特征6 — 情绪曲线太光滑**
追问：写的时候有没有哪个地方你自己也没完全想通？那个地方留着，别修圆了。

**特征7 — 替读者说一句笨话然后纠正**
追问：你替读者说的那句话，是你真的听到过别人这么说，还是你编出来方便自己反驳的？

**特征8 — 「不是X是Y」高密度**
追问：你翻转了三次，读者已经不觉得你深了。哪一次是你真正想说的？留那一次。

**特征9 — 没有任何犹豫**
追问：你这篇文章里有没有什么地方你其实也不太确定？写出来。

**特征10 — 精确到不真实的情绪细节**
追问：「1.7秒」这种数字你量过吗？用你嘴上会说的词来描述。

**特征11 — 脆弱感服务于论点**
追问：你分享的这段经历，有没有哪部分跟论点其实没关系，但你还是记得很清楚？那部分可能更真实。

**特征12 — 把结论包装成「协议」**
追问：你前面花了几千字说这件事不能被简化，结尾又给了一个简化版。这个矛盾读者能看出来吗？

**特征13 — 每个段落都有收束金句**
追问：你这篇文章最重要的一句话是哪句？让那句爆发就行，其他段落不用都收得那么漂亮。

**特征14 — 句子节奏过于均匀**
追问：你随便挑五句话数一下字数，是不是都差不多长？试试在某个地方加一句两三个字的短句。

**特征15 — 用身体感受替代论证**
追问：你用「身体知道答案」来收束，是因为你真觉得这件事没法用道理讲清楚，还是因为你讲不下去了？

**特征16 — 开头「钩子+痛点+承诺」三件套**
追问：你的前三句话在卖焦虑。你真正想让读者知道的那件事是什么？从那件事开始说。

**特征17 — 连接词过度使用且位置固定**
追问：搜一下全文里有多少个「然而」「事实上」「值得注意的是」。删掉一半，读者自己能感觉到话锋变了。

**特征18 — 同义词刻意替换**
追问：同一段里换了好几个词说同一件事。如果这个词你觉得准，重复用。重复不是错。

**特征19 — 中文翻译腔**
追问：这句话你嘴上会怎么说？那就怎么写。特别注意「作为」「关于」「基于」「进行」。

**特征20 — 虚假的「讲个故事」**
追问：这个朋友叫什么？中间出过什么差错？如果你想不起来细节，换一个你自己的经历。

**特征21 — 结尾「你值得」式祝福**
追问：删掉最后一段再读一遍。文章是不是已经结束了？

**特征22 — 对「深刻」的过拟合**
追问：你把一个实操问题升维到了哲学层面。这个话题真的需要升维吗？

### 误伤警告
| 特征 | 触发阈值 | 说明 |
|---|---|---|
| 「不是X是Y」(#8) | 800字内出现3次以上 | 鲁迅、李敖、罗翔都用 |
| 替读者说笨话(#7) | 虚构的读者声音明显被矮化 | 经典修辞prolepsis，本身不是AI特征 |
| 收束金句(#13) | 仅适用于公众号长文 | 短视频文稿段段金句是体裁要求 |
| 堵住反驳(#1) | 仅适用于自媒体/社交媒体 | 学术写作穷尽反驳是规范 |

### 体裁识别
| 体裁 | 调整项 |
|---|---|
| 短视频文稿 | 金句收束(#13)不判定；开头三件套(#16)和连接词(#17)更突出 |
| 公众号长文 | 全部22条适用 |
| 推文/社交媒体 | 句子节奏(#14)不适用（推文本身就短） |
| 学术/正式文体 | 堵反驳(#1)、知识输出(#2)不判定 |

## 十三、标题公式——12类心理触发器

核心规则：标题留悬念，不说答案。用「为什么」不用「证明」，用「问题」不用「结论」。

### 12类触发器速查表

| 类型 | 核心机制 | 最适合 |
|------|---------|-------|
| 认知冲突 | 打破已有认知 | 观点输出、科普、打破误区 |
| 好奇缺口 | 信息不对称焦虑 | 揭秘类、行业内幕 |
| 恐惧/损失 | 不点就亏 | 避坑类、警告类 |
| 身份代入 | "说的就是我" | 垂直人群、精准获客 |
| 数字锚定 | 降低认知成本 | 方法论、清单类 |
| 结果承诺 | 具体结果+时间 | 教程类、变现类 |
| 社会证明 | 案例驱动 | 经验分享、逆袭故事 |
| 争议/挑衅 | 制造站队感 | 观点类、评论区互动 |
| 场景/条件 | 精准匹配状态 | 解决方案类 |
| 行动号召 | 推动行动 | 态度类、行动指南 |
| 权威借力 | 名人/案例背书 | 方法论、案例拆解 |
| 互动/测试 | 激活参与感 | 测评类、投票类 |

### 标题质量5条铁律
1. **留悬念，不说答案。** 检查方法：看完标题，观众还需要点进来吗？如果标题已经把答案说完了，就是失败的标题。
2. **话题要扩大，不要缩窄。** 用普世词（赚钱、涨粉、不上班）替换行业术语。
3. **击中真实痛点，不是表象概念。** 「一人公司」是表象，「不上班」才是真实痛点。
4. **张力检查：至少满足2项。** 有对比/反差、有具体数字、有悬念/好奇心、有冲突/争议性、有时间承诺、有结果承诺——6项至少命中2项。
5. **公众号标题≤25字（含标点）。** 小红书≤20字。

### 匹配逻辑
- 话题有反常识 → 优先「认知冲突型」
- 话题涉及行业内幕 → 优先「好奇缺口型」
- 话题是避坑/纠错 → 优先「恐惧/损失型」
- 话题针对特定人群 → 优先「身份代入型」
- 话题是方法/步骤 → 优先「数字锚定型」
- 话题有明确结果 → 优先「结果承诺型」

## 十四、概念拆解——7张表防语言迷惑

核心使命：反对语言对理智的迷惑。商业写作中充满被语言迷惑的伪概念。

### 伪概念检测
去掉这个词，用大白话说同一件事，你还能说清楚吗？
- 如果能 → 这个词只是包装，不影响理解
- 如果不能 → 这个词在掩盖你理解的空白

### Question vs Problem
- **Question**：有标准答案，可以用线性文字回答（如"在哪里注册公司"）
- **Problem**：答案不能是文本形式的，只能是实践过程（如"怎么赚钱"）
- 大部分商业问题是Problem伪装成Question。你的文章在回答一个有标准答案的问题，还是在展示一个实践过程？后者更有价值。

### 7张表（深度观点文用）
写深度观点文时，用这7张表拆核心概念，确保每个词都有明确含义：
1. **对象表** — 基本对象（不可再分的元素）
2. **事态表** — 原子事态（最小的事实单元）
3. **复合事态表** — 由原子事态组成的复杂事实
4. **关系表** — 对象/事态间的关系
5. **规则表** — 规律和规则
6. **形式表** — 逻辑结构
7. **定义表** — 每个概念的严格定义

## 十五、选题消解漏斗

核心哲学：你的核心工作不是回答问题，是消解问题。因为问题本身可能是错的。

### 第一层：语言陷阱检测
检查选题中是否有模糊的、没被定义的核心词。
常见陷阱词：「适合」「值得」「应该」「好的」「高级」「有前景」「赛道」

**示例**：
- 「我适不适合做XX？」→ "适合"的标准是什么？年入百万叫适合的话，年入九十九万就不适合吗？
- 「我的视频不够高级」→ "高级"的定义是什么？

### 第二层：假设错误检测
检查选题背后隐含的假设是否成立。

**示例**：
- 「我想创业，但没有钱怎么办？」→ 假设：创业需要钱。但绝大多数创业项目启动初期不需要大额资金。
- 「我的产品很好但卖不出去」→ 假设：产品好=卖得出去。但能变现的产品是基于买家做的，脱离买家做产品，那不是产品，是「爱好成果」。

### 第三层：逻辑错误检测
最常见：把相关性当成因果性。

**示例**：
- 「我努力了为什么没有结果？」→ 努力→结果（因果）。实际上：拿到结果的人都努力了（相关），但努力的人不一定都拿到结果。
- 「我发了一个月公众号为什么没流量？」→ 持续发→有流量（因果）。内容质量才是因果变量。

## 十六、写作资产与复利

核心逻辑：慢方法 → 摩擦 → 判断 → 资产 → 复利。

### 摩擦是信息
手动拆解50个爆款文稿，比AI批量总结更能获得模式识别能力。拆解爆款必须手动，禁止AI代拆。

### 资产定义
| 产出类型 | 是不是资产 |
|----------|-----------|
| 一篇发出去的内容 | ❌ 不是资产，是一次性输出 |
| 一个整理好的对标分析库 | ✅ 是资产，下次可以直接调用 |
| 「心里有数了」 | ❌ 不是资产，没有外化就不可复用 |
| 一套验证过的内容模板 | ✅ 是资产，每次用都更顺手 |

### 消耗战 vs 复利游戏
- 每次从零开始 = 消耗战，靠灵感运气
- 每条内容让下一条更容易 = 复利游戏，靠系统积累
- 判断标准：这个方法做完之后，下一次会不会更容易？

## 十七、对标五重过滤

核心信念：模仿不是方法，是信仰。大部分人用"做自己"来回避模仿的难度。

### 五重过滤
1. 不讨论"适不适合我"——我们不讨论你，我们只讨论业务
2. 赚钱≠有粉丝——粉丝多不代表赚钱
3. 只看文章结构/节奏/素材，不看"是否适合我"
4. 规则 > 结果——让AI分析爆款文案是最蠢的方法
5. 对标时手动拆解，禁止AI代拆

## 十八、写作拖延自检

### 6个信号

| 信号 | 表现 | 诊断 |
|------|------|------|
| A 执行模拟器 | 收集工具、整理资料、做计划，但不写 | 把准备当成了执行本身 |
| B 思考手淫 | 反复想同一个问题，享受"准备"本身 | 用思考回避行动 |
| C 方向跳跃 | 频繁换选题，每个写不到2周 | 逃避深入（因为深入意味着可能失败） |
| D 知识上瘾 | 不停学习看课，但不开始写 | 购买"正在进步"的幻觉 |
| E 完美主义 | 因为做不到完美而不开始 | 用高标准合理化不行动 |
| F 被强迫叙事 | 把不写归咎于外部 | "被强迫"是自我欺骗 |

**一句话处方**：你不是在过度思考，你是在用思考回避行动。
