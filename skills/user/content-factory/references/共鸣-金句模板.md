# 共鸣 — 金句模板

## 可转发的金句特征

- 短：一句话说完
- 具体：有数字或对比
- 态度鲜明：不模棱两可
- 反常识：和大众认知相反

## 模板

### 模板1：不是X，是Y
- 不是我文笔好，是背后跑着一套AI内容生产系统
- 不是教程好，是我帮你踩过坑了
- 不是AI厉害，是我知道怎么让AI像我

### 模板2：我做了X，结果是Y
- 4个月变现10万，我做了这三件事
- 10天万粉，进度60/200，公开记录全过程
- 篇均12万曝光，涨粉累计9000+

### 模板3：大部分人……，但……
- 大部分人用AI做内容是碎片化的，有想法就问AI，拿到答案就发
- 大部分人写标题是拍脑袋，我是从数据里长规则
- 大部分人收藏了等于会了，我是存了就用

### 模板4：如果你……，你会……
- 如果你知道书签率0.5-1%，你会重新设计结尾
- 如果你从数据里长规则，你会少踩80%的坑

### 模板5：一句话总结
- 爆款公式：硬核教程或真实经历 + 具体数据锚定 + 可复现路径
- 底层逻辑：帮你省时间
- 核心思路：每次创作都在给系统加东西

## 金句位置

| 位置 | 作用 |
|------|------|
| 开头 | 定调，让人知道这篇文章值不值得看 |
| 中间转折 | 让人停下来想 |
| 结尾 | 让人想转发 |

## 生成方法

写完文章后，问自己：
- 哪句话可以单独发朋友圈？
- 哪句话读者会截图保存？
- 哪句话可以当标题？

没有就加一句。
