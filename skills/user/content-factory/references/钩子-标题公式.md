## 小红书标题特殊规则

### 硬性约束
- **≤20个中文字符**（含标点）—— 超出会被截断，已多次验证
- 产品名优先用英文（Obsidian、Notion、Hermes）—— 占搜索关键词

### 平台差异：搜索驱动 vs 信息流驱动

| | 公众号（信息流） | 小红书（搜索驱动） |
|---|---|---|
| 用户状态 | 无目的刷到 | 带着具体问题搜进来 |
| 标题功能 | 制造情绪让人点 | 帮用户判断"这篇能解决我的问题" |
| 核心元素 | 硬数字+冲突+情绪 | 具体产品名+反常识结论 |
| 爆款结构 | "从0-1带你..." "突发/怎么办" | "Obsidian+AI，我放弃了整理" |

### 验证过的小红书标题公式

**公式A：产品名 + 反常识结论**
- Obsidian+AI，我放弃了整理笔记（14字，215浏览）
- 试了47个笔记App，最后只留这1个
- 打工人别折腾了，这1个App够用到退休

**公式B：时间/数量背书 + 具体转变**
- Obsidian用了3年，接入AI后不用整理了
- 笔记过千后我悟了：不用花时间整理

**公式C：痛点 + 解决方案暗示**
- 终于不用选笔记App了，就它
- 我的2025年度生产力工具，杠杆力拉满

### 标题-封面图对齐原则

**致命错误：** thumbnail 写"不用花时间整理"，标题写"没有AI的笔记系统真痛苦"
→ 用户看图想点，看标题又犹豫，预期落差

**正确做法：** 标题和 thumbnail 的核心信息必须一致
- thumbnail："不用花时间整理" → 标题："Obsidian+AI，我放弃了整理笔记"
- thumbnail："替你试完4个工具" → 标题："试完4个笔记工具后，我留下了这个"

### 小红书标题禁忌

- 不用抽象主语："笔记系统""效率工具""知识体系"
- 不用纯情绪无对象："真痛苦""我悟了"（悟了什么？）
- 不用过程描述无结论："AI工具那么多，我先替你试一圈"
- 不用反问无答案："我舍弃了Notion、Obsidian、flomo选了。。"
