# 小红书封面图 AI 提示词模板

## 用途
用户需要为小红书文章生成封面图，要求差异化风格（避免抄袭嫌疑），支持多种视觉风格。

## 核心原则
- 差异化：避开原图的"科技风深色渐变+对称气泡"布局
- 信息密度：左痛点右解决方案的结构可以保留，但视觉语言要换
- 平台适配：9:16竖版，文字清晰可读

## 风格一：手绘涂鸦风

### 描述
粗糙纸张背景，手写马克笔字体，彩色便利贴散落，有涂改痕迹和高亮笔迹，像真实笔记本页面。

### NanoBanana / Midjourney 提示词
```
手绘涂鸦风格，白色粗糙纸张背景，中央"Obsidian 开荒指南"用黑色马克笔手写粗体字，周围散落彩色便利贴和箭头，左便签写痛点"插件太多""不会开始"红笔圈出，右便签写解决"其实不难""三步上手"绿笔打勾，有涂改痕迹和手绘高亮，像真实笔记本页面，无对称布局，随意自然，小红书教程封面，9:16竖版
```

### 适用场景
- 知识工具类内容（Obsidian/Notion/效率工具）
- 需要降低"设计抄袭"感
- 强调"真人用过后的分享"

## 风格二：复古打印风

### 描述
泛黄牛皮纸/报纸纹理，打字机字体，老式表格排版，有咖啡渍和折痕，像1980年代电脑手册。

### 提示词
```
复古打字机风格，泛黄牛皮纸纹理背景，中央黑色粗体打字机字体"OBSIDIAN 开荒指南"，副标题红色印章风格"一点都不难"，左右两栏老式表格排版，左栏"新手常见问题"黑框列表，右栏"解决方案"红框列表，有咖啡渍和折痕纹理，像1980年代电脑手册，极简无装饰，小红书封面，9:16竖版
```

### 适用场景
- 技术教程类内容
- 需要"权威感"和"专业感"
- 男性用户为主的领域

## 风格三：极简线稿风

### 描述
纯白背景，单线条字体，大量留白，无气泡无底色，像日本杂志排版。

### 提示词
```
极简黑白线稿风格，纯白背景，中央只有一行黑色细线字体"Obsidian 开荒指南"，下方细线分隔，左侧零散短句"插件太多""不会同步""文件夹乱"，右侧对应短句"只需10个""三步设置""一键模板"，无气泡无底色纯文字排列，大量留白，像日本杂志排版，冷淡高级感，小红书封面，9:16竖版
```

### 适用场景
- 高级感/冷淡风定位
- 女性用户为主的小红书内容
- 需要与"热闹"的竞品形成反差

## 风格四：漫画分镜风

### 描述
漫画格子布局，简笔画人物，对话框形式呈现痛点和解决方案，轻松幽默。

### 提示词
```
漫画分镜风格，白色背景，4-6个漫画格子，简笔画新手人物表情焦虑（左列），同一人物表情放松（右列），对话框文字"插件太多怎么办？""三步搞定！"，粗黑边框线条，少量彩色点缀，像日本四格漫画，轻松幽默，小红书教程封面，9:16竖版
```

### 适用场景
- 轻松向教程
- 年轻用户群体
- 需要情绪共鸣的内容

## 生成后调整建议

如果AI生成效果不佳：
- 气泡位置不对 → 加 `perfectly symmetrical layout` 或 `left column aligned left, right column aligned right`
- 文字不清晰 → 加 `crisp readable text, high contrast`
- 风格不统一 → 加 `consistent [风格名] style throughout`

## 替代方案：Canva/稿定设计

如果AI生成不稳定，直接用模板工具：
1. 打开 Canva 或 稿定设计
2. 搜"小红书封面"
3. 选对应风格模板（手绘/复古/极简）
4. 替换文字，调整颜色
5. 导出PNG

优势：可控、快、不需要调提示词。
劣势：可能与其他用户撞模板。

## 选择建议

| 用户状态 | 推荐风格 | 原因 |
|---------|---------|------|
| 强调"真人经验" | 手绘涂鸦 | 降低距离感，增加可信度 |
| 强调"专业权威" | 复古打印 | 知识工具类天然适配 |
| 强调"高级感" | 极简线稿 | 与热闹竞品形成反差 |
| 强调"轻松有趣" | 漫画分镜 | 情绪共鸣强 |
