# 价值 — 收藏理由

## 为什么收藏

用户收藏 = 觉得有用，但现在用不上，以后用。

## 高收藏率内容类型

| 类型 | 收藏理由 | 例子 |
|------|---------|------|
| 教程/步骤 | 可以照着做 | 从0-1带你了解Notion |
| 资源合集 | 以后找得到 | 20+出海站工具清单 |
| 框架/系统 | 可以复用 | AI内容生产系统 |
| 数据/规律 | 有参考价值 | 篇均12万曝光的数据复盘 |
| 避坑指南 | 防止自己踩 | 踩了什么坑 |

## 收藏率数据

- 篇均书签率：0.5-1%
- AI算命那篇最高：1.01%
- AI+搞钱+信息差组合，读者存得最积极

## 让内容值得收藏的技巧

1. **步骤化**：每步可执行，不是概念
2. **具体数字**：4个月、10万、452%，不是"很快""很多"
3. **可复现路径**：我做了X，结果是Y，你也可以
4. **资源附赠**：工具清单、模板链接、代码片段
5. **时间戳**：2026年5月最新，不是永远有效

## 收藏率低的特征

- 纯观点，无操作步骤
- 抽象概念，无具体案例
- 情绪宣泄，无实用价值
- 过时信息

## 结尾加收藏引导

- "建议收藏，以后用得上"
- "存下来，下次做的时候照着来"
- "这篇我整理了很久，觉得有用就存一下"
