# 小红书效率工具赛道竞品分析案例

## 分析日期
2026-05-12

## 分析对象
Obsidian / 笔记App / 效率工具 小红书赛道

## 搜索关键词与结果

### 1. "Obsidian 新手"
- 7个必装插件 — 601赞（3天前）
- 开荒指南 — 2274赞
- 零基础入坑 — 382赞
- 超级新手指南 — 387赞
- 零基础入坑：从安装到第一个笔记 — 2358赞

**洞察**：教程泛滥，同质化严重，"7个插件"重复出现。

### 2. "Obsidian 插件"
- 7个必装插件 — 2895赞
- 30款宝藏插件 — 166赞
- 10大热门插件 — 265赞
- 2026黑马插件 — 863赞

**洞察**：插件推荐极度内卷，数字越卷越大（7→10→30），但赞数不增反降。

### 3. "笔记软件 只用一个"
- 3个APP构建系统 — 5628赞（但标题是"3个"不是"1个"）
- 我舍弃了Notion/Obsidian/flomo选了。。 — 308赞（标题没给答案）
- Obsidian替代品 — 243赞
- 8个top笔记APP — 1152赞

**洞察**："一个就够"定位几乎空白，全是罗列多个工具。

### 4. "Notion 换 Obsidian"
- 用了3年Notion迁移到Obsidian — 37赞
- 让Obsidian变Notion — 145赞
- 90%的人选错了 — 240赞
- 在Obsidian中像Notion一样复盘 — 1178赞

**洞察**：迁移教程多，但赞数普遍不高（37-296区间），情绪共鸣弱。

### 5. "Obsidian 放弃" ⭐ 关键发现
- 又试用了两个星期Obsidian，还是弃了吧 — 555赞
- Obsidian有点折腾不动了 — 275赞
- 用了4年Obsidian劝老婆别用 — 120赞
- 我删掉了Obsidian — 67赞
- obsidian在AI时代已失去意义 — 1790赞

**洞察**：反Obsidian内容情绪高、赞数高，但**没人给替代方案**。这是最大空白区。

### 6. "笔记App 推荐"
- 过了沉迷工具的年纪 — 1032赞
- 差生文具多 — 100赞
- 为什么大家都好喜欢obsidian — 1441赞（反方吐槽）

### 7. "知识管理"
- Obsidian别再手动整理了，让AI来 — 2154赞
- Obsidian已经不够用了，知识管理3.0 — 610赞
- 怕被蒸馏用Obsidian+AI — 182赞

## 爆款规律总结

### 高赞公式
1. 数字冲突 + 明确结论：`试了47个笔记App，最后只留这1个`
2. 身份痛点 + 神器定位：`打工人别折腾了，这1个App够用到退休`
3. 反转/情绪释放：`终于不用选笔记App了，就它`
4. 年度盘点 + 情绪词：`我的2025年度生产力工具，杠杆力拉满！`

### 低赞陷阱
1. 过程描述无结论：`AI工具那么多，我先替你试一圈`（2赞）
2. 纯教程无情绪：`Obsidian官方推荐保姆级实操手册`（144赞）
3. 反问无答案：`我舍弃了Notion、Obsidian、flomo选了。。`（308赞）

### 情绪流量方向
- 反Obsidian > 挺Obsidian（1790赞 vs 2895赞但后者是红海）
- 放弃/吐槽 > 安利/教程（555赞弃坑 vs 144赞教程）
- "一个就够" > "8个推荐"（空白区 vs 红海）

## 差异化机会

| 方向 | 竞争度 | 情绪值 | 建议 |
|------|--------|--------|------|
| 插件推荐 | 极高 | 中 | 避开 |
| 新手教程 | 高 | 中 | 避开 |
| 反Obsidian+给替代方案 | 低 | 高 | **主攻** |
| "一个就够"定位 | 极低 | 高 | **主攻** |
| AI+Obsidian | 中 | 高 | 可切入，但需差异化 |

## 最终选题

基于以上分析，选定标题：
**"笔记过千后我悟了：没有AI的笔记系统都是摆设"**

理由：
- 数字冲突（过千）+ 极端结论（都是摆设）
- 蹭AI热点但不讲AI多强，讲"没有AI多惨"（反常识）
- 不卷插件、不卷教程，讲工作流和认知
- 手绘涂鸦风格差异化视觉
