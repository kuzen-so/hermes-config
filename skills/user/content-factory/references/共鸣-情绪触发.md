# 共鸣 — 情绪触发

## 点赞的心理

点赞 = 认同你这个人，或认同你说的某句话。

不是内容有用，是"你懂我"。

## 高点赞内容特征

| 情绪 | 触发方式 | 例子 |
|------|---------|------|
| 共鸣 | 说出读者想说但没说的话 | "拼凑感是因为没有骨架" |
| 认同 | 观点鲜明，不模棱两可 | "公众号就是下沉市场" |
| 解气 | 吐槽共同痛点 | "AI味一重就感觉不对" |
| 希望 | 展示可能性 | "10天万粉，进度60/200" |
| 好奇 | 反差/悬念 | "452%收益率，我怎么做到的" |

## 个人故事的力量

小红书核心：个人故事 > 教程

公式：
```
我遇到了XX问题 → 试了很多方法 → 终于找到YY → 分享给你
```

不是"教你做"，是"我做了，你也可以"。

## 情绪曲线

文章情绪节奏：
1. 开头：痛点/共鸣（低）
2. 中间：转折/发现（高）
3. 结尾：希望/行动（中高）

不要平。有起伏才有情绪。

## 金句位置

金句放在：
- 段落结尾（让人想划线）
- 文章结尾（让人想转发）
- 转折处（让人停下来想）

## 禁忌

- 替读者说话：「你可能觉得……」
- 说教感：「记住」「一定要」
- 虚构共鸣：「90%的人不知道」
