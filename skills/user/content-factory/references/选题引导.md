# 选题引导 — 不知道写什么的时候

## 触发条件
用户说：
- "不知道写什么"
- "没选题"
- "选题荒"
- "不知道发什么"
- "没灵感"

## 执行流程

### 1. 读数据复盘
```
cat ~/Documents/Obsidian/10-Work/rule/数据复盘.md
```
找出：什么类型爆了？继续写同类。

### 2. 读素材库
```
grep -r "" ~/Documents/Obsidian/10-Work/clip/ | head -20
```
找出：有什么金句/概念/案例可延伸成文章？

### 3. 读当前选题池
```
ls ~/Documents/Obsidian/10-Work/idea/
```
找出：有多少选题？缺什么类型？

### 4. 给出建议

输出格式：
```
当前选题池：X个选题，缺XX类型

建议选题（3-5个）：
1. [选题名] — 来源：XX爆了，延伸角度
2. [选题名] — 来源：clip素材延伸
3. [选题名] — 来源：热点嫁接
4. [选题名] — 来源：旧文翻新
5. [选题名] — 来源：读者反馈

选一个，我帮你写。
```

## 选题来源优先级

| 优先级 | 来源 | 为什么优先 |
|--------|------|-----------|
| 1 | 已爆类型延伸 | 验证过，读者买账 |
| 2 | 素材库延伸 | 有现成内容，快 |
| 3 | 热点嫁接 | 流量窗口 |
| 4 | 旧文翻新 | 爆款更新，稳 |
| 5 | 读者反馈 | 精准需求 |

## 选题检查

每个建议选题必须能回答：
- 什么平台？（公众号/小红书）
- 什么类型？（教程/故事/复盘）
- 有什么素材？（在clip/里有吗）
- 预计数据？（参考同类历史数据）

答不上来 = 不建议。
