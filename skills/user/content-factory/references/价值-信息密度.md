# 价值 — 信息密度

## 原则

每段都有可带走的东西。

读者看完一段，要么学到一招，要么记住一个数字，要么想转发一句话。

## 信息密度检测

| 低密度（删） | 高密度（留） |
|-------------|-------------|
| "大家都知道……" | "4个月变现10万，我做了这三件事" |
| "简单来说……" | "步骤1：打开设置→找到XX→勾选这个" |
| "我认为很重要" | "书签率0.5-1%，这篇1.01%——AI+搞钱+信息差" |
| "赋能、闭环、底层逻辑" | "用对X，你的Y瞬间提升" |

## 段落标准

每段必须包含至少一个：
- 具体数字
- 可执行步骤
- 对比/反差
- 金句

没有就删或合并。

## 公众号信息密度

1500-3000字，分6-8个小节。
每节一个核心点，配一个案例或数字。

## 小红书信息密度

300-800字，分4-6段。
每段一个信息点，不要铺垫。

## 检查方法

写完问自己：
- 这段话删掉，读者会损失什么？
- 如果损失不大，删掉。
- 如果损失大，保留并加粗关键句。
