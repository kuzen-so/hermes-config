# 小红书写作规范

## 核心原则

- **不主动生成文章**。等用户明确说"写"或"帮我写"才进入写作模式。
- 日常聊天 ≠ 内容生产。用户分享观察、吐槽、思考时，不要滑向"那我帮你写一稿"。
- **不反问用户，不问"清楚了吗？"** — 用户认为这类结尾问题打断思路。用陈述句或直接停止。
- **软垂直的本质：解决问题就写。** 不管什么事，只要指向"解决一个具体问题"，就符合核心标签。不需要纠结这件事本身垂不垂直。

**内容公式：** 工具是入口 → 焦虑是钩子 → 身份才是出口

**身份与垂直的冲突警告：**
身份卖的是"工具解脱"，但硬垂直 Obsidian 教程卖的是"工具深入"。这两个信号会互相打架：
- 想看教程的人点进来，发现你在说"工具没用"，觉得被耍了
- 想解脱的人关注你，结果你在讲插件配置，觉得你也在制造焦虑

**解决：** 软垂直——借 Obsidian 讲"如何从工具依赖里觉醒"，不是教 Obsidian。

**变现路径冲突：**
- 身份方向（"缺的不是工具，是自己"）→ 心法课、陪伴社群、身份认同
- 硬垂直方向（Obsidian 教程）→ 模板售卖、插件推荐、配置服务
- 两条路都能走通，但混在一起会让粉丝不知道你是干嘛的，两头不靠

**数据验证：**
- "卸载 Openclaw 后用 Hermes"（215浏览）→ 产品对比，偏工具，数据好
- "笔记过千后我悟了"（55浏览）→ 身份顿悟，偏情绪，标题没放 Obsidian 导致搜索没命中

## 选题规则

- **解决问题就写** = 软垂直的核心筛选器
- **评论区找选题 > 搜索找选题**。评论区有真实痛点+情绪（"笔记过千后搜索不到，标签也乱了，崩溃"），搜索只是泛泛的"我想要什么"。
- 刷评论区找选题时，只收集"工具焦虑"类评论（"笔记多了找不到""整理到崩溃""试了无数工具还是焦虑"）
- 跳过"工具怎么配置""哪个功能更好用"类评论——那是硬垂直/教程方向，和身份冲突
- **刷评论区是时间黑洞，必须给硬边界**：只刷 10 分钟 / 只记 3 个选题 / 不点进正文 / 只刷评论区不刷正文
- **没有标准 SOP 找选题**，因为真实需求在评论区，不是关键词搜索能覆盖的

## 标题规则（硬限制）

- **≤20个中文字符**，标点、数字、英文算1格。用户已多次纠正我忘记此限制，必须强制执行。
- **必须有具体产品名或关键词**（Obsidian、Notion、Hermes、Raycast 等），占领搜索流量。
- **标题和 thumbnail 信息对齐**。thumbnail 上的核心卖点必须在标题里出现，避免预期落差。
- 小红书 = **有目的搜索 / 解决生活具体问题**，不是公众号的信息流情绪。
- 个人故事要包装成解决方案，不是纯叙事。

**成功案例：**
- "Obsidian+AI，我放弃了整理笔记"（14字）— 产品名+反常识结论，和 thumbnail"不用花时间整理"对齐，验证通过。

## 我的可靠性规则（防止出错）

- **聊到小红书 → 先加载本 skill → 再读身份文档**（路径见上）。顺序不能颠倒。
- **用户说过的新规则 → 当场写进本 skill**，不拖。Memory 会满，skill 不会。
- **不确定的事 → 直接说"我不确定，查一下"**，不硬编。硬编一次，信任崩一次。
- **身份文档在 Obsidian 里，不在 session 历史里**。不要搜 session_search 找身份定位，直接读文件。
- **20字限制、身份主张、垂直方向**——这三项如果和用户说的矛盾，以用户说的为准，当场更新 skill。
- **不要反问用户"清楚了吗？"** — 用户认为这类结尾问题打断思路。用陈述句或直接停止。

- 越贴近生活、越具体，点击率越好。
- 用户带着问题搜进来，标题要像搜索关键词。
- 情绪可以有，但必须依附在具体动作/结果上。

## 垂直问题

- 不用纠结"这件事垂不垂直"。
- 关键是让不同的事经过同一个"你"的滤镜，收拢到核心标签下。
- 核心标签未定就讨论，定了就执行.

### 硬垂直 vs 软垂直

| | 硬垂直 | 软垂直 |
|--|--------|--------|
| 做法 | 只发一类内容，其他不发 | 不同内容都经过同一个核心滤镜 |
| 代价 | 牺牲真实感，标签清晰 | 需要提炼核心标签，否则显乱 |
| 适合 | 已有明确定位 | 还在探索期 |
| 风险 | 内容枯竭，人设僵硬 | 标签模糊，用户认知分散 |

**软垂直的本质：解决问题就写。**

不管什么事，只要指向"解决一个具体问题"，就符合核心标签。不需要纠结这件事本身垂不垂直。

示例：
- 硬垂直：只发 Obsidian 教程
- 软垂直：游戏闪退也发，但标题写成"Mac游戏闪退排查，这3个设置我试了一遍"——指向"解决问题"这个核心
