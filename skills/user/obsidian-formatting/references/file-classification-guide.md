# Obsidian 文件分类归位指南

## 用户文件夹结构

| 编号 | 文件夹 | 用途 |
|------|--------|------|
| 1- | `1-Inbox` | 收件箱 |
| 2- | `2-Box` | 暂存 |
| 10- | `10-Content Factory` | 内容工厂 |
| | ├── `clip/` | 剪藏 |
| | ├── `draft/` | 草稿 |
| | ├── `idea/` | 灵感 |
| | ├── `rule/` | 规则 |
| | └── `voice/` | 成稿（含日记） |
| 11- | `11-Processing` | 处理中 |
| 12- | `12-Output` | 输出（成品文章/教程） |
| 96- | `96-Archive` | 归档（废弃/过期） |
| 97- | `97-Weeks` | 周报 |
| 99- | `99-Personal` | 个人（私人数据/执行计划） |

## 归位判断标准

| 问题 | 去这里 |
|------|--------|
| 是成品文章/教程，可发布或分享？ | `12-Output/` |
| 是个人数据、执行计划、仅自己用？ | `99-Personal/` |
| 是内容生产的方法论/规则？ | `10-Content Factory/rule/` |
| 是草稿/未完成？ | `10-Content Factory/draft/` |
| 是剪藏的网页/文章？ | `10-Content Factory/clip/` |
| 是灵感/碎片想法？ | 日记（`voice/Days/`） |
| 已废弃/过期/不再更新？ | `96-Archive/` |
| 正在处理中？ | `11-Processing/` |

## 关键原则

- **Archive ≠ 已完成封存**：Archive 是墓地，放废弃内容。已完成但有价值的放 Output
- **Output = 可发布**：不是"我写完的东西"，是"可以给别人看的东西"
- **Personal = 私人**：身高体重、护肤计划、个人配置，仅自己用
- **日记 = 一切碎片**：灵感、概念、流水账，一行一段，不分类
- **不要建碎片文件夹**：用户明确拒绝，认为是自我欺骗

## 常见误区

| 误区 | 正确 |
|------|------|
| "结束了=归档" | 结束了 + 有价值 = Output |
| "这是我的输出" | 个人计划 ≠ Output，Output 是可发布的 |
| "建个碎片文件夹" | 用户拒绝，碎片放日记 |
