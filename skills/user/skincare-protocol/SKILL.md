# Skincare Protocol

## Core Philosophy

- 减法优于加法：先移除错产品，再加新东西
- 一次只改一样，3天验证
- 测量优于目测：油出现时间、刺激频率
- 不囤产品，用完再买

---

## 1. 诊断问题（全部问，不跳过）

1. 晨间流程：具体产品和顺序
2. 晚间流程：具体产品和顺序
3. 肤质：油/干/混合/敏感
4. 出油时间：洗脸后几小时出油？
5. 主要目标：控油/祛痘/去黑头/缩毛孔/均匀肤色
6. 日晒：室内靠窗？户外？当前防晒状态？
7. 现有产品清单及浓度（如"20%壬二酸"）

---

## 2. 常见陷阱

| 陷阱 | 表现 | 修复 |
|------|------|------|
| 油皮+封闭保湿 | 角鲨烷、厚重面霜→下午油崩 | 换透明质酸/轻薄乳液 |
| 过度清洁 | 皂基/强起泡→屏障损伤→代偿出油 | 换氨基酸洁面 |
| 酸类不保湿 | 刺激→更差屏障→更差外观 | 酸后厚涂B5 |
| 酸类不防晒 | 色沉 | 出门必防晒 |
| 补充装无泵头 | 残留污染、折腾 | 买正装 |
| 洁面营销成分 | 神经酰胺/玻尿酸/美容液→停留30秒冲走，零价值 | 不为这些买单 |
| 限时新客价 | 比价时确认是否为常态价 | 看常规价 |

---

## 3. 调整规则

- **一次改一样**，3天验证
- 油皮：封闭剂→透明质酸/轻薄乳液
- 酸类夜晚：酸→等10分钟→厚涂B5→15分钟→吸掉多余→睡
- **B5厚敷**：涂到肉眼可见白色，非薄透；等15分钟；湿巾擦掉；留薄层；不冲洗
- **壬二酸+B5顺序**：壬二酸→等5-10分钟完全干→再B5。**酸湿时不上B5**，湿封闭增加渗透深度和刺激风险
- **壬二酸耐受建立**：
  - 第1周：隔天，点涂（T区/痘区）
  - 第2周：如无刺激→每天
  - 任何阶段痒/刺痛→退回上一频率
- **痒应急**：今晚停壬二酸，清洁+薄B5；明天还痒→停B5，仅清洁1-2天至屏障恢复；再重启壬二酸，更低频/点涂
- 洁面：油皮用氨基酸，非皂基/强起泡
- **闲置处理**：封闭面霜（角鲨烷）→收好等脱皮/冬天/身体用，非油皮日常
- **手部卫生**：脏手摸脸→细菌/油脂转移→更痘更油

## 4. 产品选择（节俭模式）

| 品类 | 底线选择 | 价格 | 升级 |
|------|---------|------|------|
| 氨基酸洁面 | 旁氏米粹/芙丽芳丝/多芬泡泡/John Jeff油橄榄慕斯 | ¥25-40 | 大厂稳定即可 |
| 壬二酸 | John Jeff 20% | ¥40-50 | 希川科颜20%（乳质地更轻薄，刺激更低） |
| 防晒 | 摇摇乐质地 | ¥30-60 | 出门必用 |
| B5 | 任意品牌泛醇精华/霜 | ¥30-80 | 修复用 |

**不为洁面营销成分买单**：神经酰胺/玻尿酸/油橄榄在洁面中不驻留，冲水带走。
**不囤**：用完再买，不提前备货，不追求完美方案先跑起来。

### 浓度选择
- 油皮、耐受、目标"看起来干净"→20%壬二酸
- 10%/15%仅适合：敏感肌入门、或20%刺激无法耐受
- 已在用20%且无刺激→不降级

## 5. 面部外观（非脂肪因素）

| "累"的来源 | 检查 | 修复 |
|-----------|------|------|
| 自我感知偏差 | 自拍（畸变）vs他人拍 | 后置相机1.5米 |
| 眼周 | 睡眠+热敷 | 非产品 |
| 下颌线 | 2-3天刮一次，不中间状态 | 非护肤 |
| 表情习惯 | 放松眉眼 | 练习：抬眉、舌顶上颚、收下巴 |
| 相机角度 | 镜头低于眼位 | 高于眼位拍 |

## Pitfalls

- 给多选项→一条推荐，被拒改一条替代，不给A/B/C
- 解释 premium 边际好处→直接答值或不值
- 用户说"等X到货"→接受延迟
- 跳过诊断问题→每个跳过都产出失败方案
- 替用户写方案→给模板留空，强制填第一条，验证后再继续
