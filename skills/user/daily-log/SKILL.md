# Daily Log

## Core Philosophy

- 先存后理，不存就忘
- 不分类，降低记录阻力
- 一行一条，极简格式
- 定期清理（建议每周）

## 记录格式

```
YYYY-MM-DD HH:MM | 内容
```

或更简：

```
- 内容
```

## 存放位置

默认：`1-Inbox/log.md`

或用户指定路径。

## 使用方式

用户说"记一下"，直接追加到 inbox 文件。不追问分类、不追问优先级。

## 示例

```
2026-05-18 17:30 | 水杨酸今天泛红，可能是天气热屏障变薄
2026-05-18 17:35 | skill 触发模式：消息、Command、定时、Webhook
2026-05-18 17:40 | 记得买鸡蛋
```

## Pitfalls

- 追问"放哪个分类"→不分类，直接存 inbox
- 追问"重要吗/紧急吗"→不判断，先存
- 整理成瘾→每周清一次，不是每次记完就整理
